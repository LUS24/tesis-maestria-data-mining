# Lista de verificación

## Contenido del artículo

- [ ] Resumen dentro del límite de palabras (generalmente 250-300 palabras)
- [ ] Contenido principal dentro del límite de páginas
- [ ] Referencias completas y verificadas
- [ ] Sección de limitaciones incluida
- [ ] Todas las figuras/tablas tienen leyendas
- [ ] Las leyendas son autocontenidas

## Formato

- [ ] Plantilla correcta utilizada (específica de conferencia y año)
- [ ] Márgenes no modificados
- [ ] Tamaños de fuente no modificados
- [ ] Requisitos de doble ciego cumplidos
- [ ] Números de página (para revisión) o ninguno (versión final)

## Técnico

- [ ] Todas las afirmaciones respaldadas por evidencia
- [ ] Barras de error incluidas
- [ ] Líneas de base apropiadas
- [ ] Hiperparámetros documentados
- [ ] Recursos de cómputo indicados

## Reproducibilidad

- [ ] Código estará disponible (o justificación)
- [ ] Datos estarán disponibles (o justificación)
- [ ] Entorno documentado
- [ ] Comandos para reproducir provistos

## Ética

- [ ] Impactos más amplios considerados
- [ ] Limitaciones declaradas honestamente
- [ ] Licencias respetadas
- [ ] IRB obtenido si es necesario

## Verificaciones finales

- [ ] PDF compila sin errores
- [ ] Todas las figuras se renderizan correctamente
- [ ] Todas las citas se resuelven
- [ ] Material suplementario organizado
- [ ] Lista de verificación de la conferencia completada
